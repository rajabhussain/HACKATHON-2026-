HCM Lite (HTML + CSS + JavaScript, no install needed)

Run: double-click index.html (Chrome/Edge), or VS Code > right-click index.html > Open with Live Server.
Keep the 3 files together in one folder: index.html, style.css, app.js

First run: create company + Admin account. Admin creates HR login; HR registers employees.
Data is saved in the browser (localStorage). To reset: DevTools > Application > Local Storage > clear.
